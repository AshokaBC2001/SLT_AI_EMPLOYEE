# duplicate-check

Starts when: the profile is ready
Done by: plain code

## What it does
- The same file cannot be added twice (checked when the HR officer uploads it).
- If the email in this CV is already used by another candidate, the candidate is marked
  "Possible duplicate" for the HR officer. Nothing is deleted.
- If the email typed by the HR officer is different from the email in the CV, that is marked too.
